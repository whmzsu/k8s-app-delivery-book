# 备份恢复演练报告（模板）

| 项 | 取值 |
|---|---|
| 日期 | 待演练脚本写入 |
| 目标集群 | 演练专用集群 context，非生产 context |
| 备份名 | 来自 velero backup get 的最近一次 Completed 备份 |
| 恢复命名空间 | order-demo-restore |
| 恢复订单行数 | 待脚本写入 |
| 新列缺失行数 | 待脚本写入（必须为 0） |
| 一致性校验 | 通过 / 不通过 |
| 责任人 | 发布值班（主）／ 数据 owner（备） |
| 结论 | 未演练过的备份不算备份；本报告须归档到发布 PR |

演练频率：每季度一次，并在每次 contract 阶段之前追加一次。
失败处置：立即停止 contract，回 16.4 检查备份凭据、卷快照与 PGDATA 路径。
