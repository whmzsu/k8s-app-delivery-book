## 变更规则（硬性）

1. **先改资产包，再改章节**。任何术语、章号、坐标、案例字段、版本基线、引用编号的改动，先在本目录落文件，再按 `strong-pairs.md` 列出受影响章节逐一同步。
2. **变更留痕**。每次改动在 `consistency-log.md` 登记：改了什么、为什么、影响哪些章、在哪个轮次回写。
3. **正文不写裸 URL**。引用一律走 `references/chNN.yaml`，正文只出现 `[R-XX-N]` 角标。
4. **卡片不写死 URL**。P1 只写来源名称；P2 分配编号与占位；P3 成稿时核验；P4 生成附录 I。
5. **口径冲突以优先级裁决**：第十一节（推进策略）> 第十节（背书）> 第九节（v3.1 逻辑线）> 第一至八节。裁决结果记入 `consistency-log.md`，并回写冲突位置。
