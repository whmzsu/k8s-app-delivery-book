# 检查清单母版（checklist-master）

版本 `v0.1` · 2026-11-10 · 附录 B 由本文件与各章专有项生成

> **质量规则**：清单条目不能只写「检查 XXX」，必须写清 **怎么查（命令/路径）+ 通过标准 + 失败怎么办**。否则等于没写。每章清单固定含 2–3 条安全项（9.6），让横切 A 真正落到每一环。

## 三、每章清单的生成规则

1. 从母版挑适用项（引用编号即可，**不要重复抄全文**，避免 31 章重复注水）
2. 补 3–5 条本章专有项，编号 `CL-<章号>-xx`，同样写清「怎么查 / 通过标准 / 失败处置」
3. 固定含 2–3 条 `CL-S-xx`
4. 章末检查清单与「依据与延伸阅读」是两段，不要合并
5. 附录 B 从母版 + 各章专有项汇总生成，可打印

## 四、卡片与详纲里的落点

- P1 章卡片：只写「清单条目数 + 2–3 条安全项的编号」，不展开
- P2 详纲：列出本章专有项的标题
- P3 成稿：写完整四列
